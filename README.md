# Home Price Prediction App

This project predicts Bangalore home prices from a simple web form using a trained machine learning model.

## Features
- Frontend UI for entering house details
- Backend API for prediction and location lookup
- Vercel-ready deployment setup

## Tech Stack
- HTML/CSS/JavaScript
- Python + Flask
- NumPy

## Run locally

### Backend
```bash
python app.py
```

### Frontend
Open the HTML file in the browser or serve the client folder with a static server.

## Deploy on Vercel
The repository includes Vercel configuration for the frontend and Python API.
